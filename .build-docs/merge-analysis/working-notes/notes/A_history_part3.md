### Plain-English glossary (terms used below)

- **Commit** - one saved change in the project history. **Diff** - the exact lines added/removed in a commit.
- **Tkinter / Tk** - the basic window toolkit that ships with Python; A's whole GUI is built with it. **ttk** - Tk's "themed" widgets (buttons, notebooks, trees) whose colours come from shared **styles** rather than from each widget. A **style map** is the part of a style that says "use this colour when the widget is selected/disabled/...".
- **Widget** - one on-screen element (a label, a button, a frame). **Frame / Canvas** - container widgets; a canvas can scroll.
- **Notebook / tab** - the row of "Step 1 ... Step 4" tabs.
- **Event / binding** - Tk calls a function ("handler") when something happens (mouse wheel, pointer entering a widget). **bind_all** - a binding for the whole application, not one widget. **unbind_all** - removes ALL such application-wide bindings for that event. **add='+'** - "add my handler next to the existing ones" instead of replacing them.
- **Worker thread** - a second line of execution so long jobs do not freeze the window. Tk is not thread-safe, so worker threads should hand screen updates to the main thread with `root.after(0, ...)` ("marshalling").
- **Import** - Python loading another file/module. An **ImportError / ModuleNotFoundError** is the error when a module is missing. A **guarded import** is `try: import x / except ImportError: ...` so a missing module does not crash the program.
- **pywin32** - the Windows-only Python package that lets Python drive Excel through **COM** (Windows' "remote control" mechanism for other programs). It installs importable modules named `pythoncom`, `win32com`, `win32api`, `win32con`, `win32gui`. **Excel COM** = driving the real Excel this way.
- **openpyxl** - a Python library that reads/writes .xlsx files without Excel. Per the author's Standard 12, saving a workbook with openpyxl drops its **Power Query** queries (Excel's data-import/refresh feature inside the report templates).
- **find_spec** - a Python function that asks "could this module be found?" without actually importing (running) it.
- **pip** - Python's package installer. **requirements.txt** - the list of packages the app needs.
- **Interpreter** - the Python program that runs the app. `py` and `python` on Windows can start different interpreters; **python3.14t** is the "free-threaded" build of Python 3.14.
- **pythonw** - the Windows Python that runs with no console window (Standard 13); there `sys.stdout`/`sys.stdin` are `None`, so `print()` shows nothing and `input()` fails.
- **Subprocess** - a separate program started by the app (here: pip, or a fresh copy of the app).
- **Weak reference / WeakKeyDictionary** - a lookup table that does not keep its keys alive; when a widget object is garbage-collected its entry disappears.
- **Mutation check** - deliberately re-breaking the code to prove a test would catch it.
- **Regression** - something that used to work and was broken by a later change.
- **Stub** - a fake module I wrote so Windows-only imports succeed on Linux for a test run. **xvfb** - an invisible screen so Tk can run on this server.
- **Dead code** - code/data that is defined but never used.
