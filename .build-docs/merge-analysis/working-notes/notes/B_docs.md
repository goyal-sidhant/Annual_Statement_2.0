### 0.2 Labels

- **READ** = established by reading code or git output. **RAN** = I executed something (scripts in `/root/merge-scratch/run/B-D/`, results in Section 10).
- **HIGH / MEDIUM / LOW** = my confidence in an inference.
- Verdicts: **STILL TRUE** (true in B's code today) / **NO LONGER TRUE** (was true when the README was written, changed since — B commit named) / **NEVER TRUE** (wrong even when written, i.e. in the shared code @d674386 / @47a1492, and still wrong) / **CANNOT VERIFY** (needs Windows, Excel, a real template, the author, or is opinion) / **PARTLY** (part right, part wrong — the split is spelled out) / **NOT APPLICABLE ANY MORE** (refers to files B deleted).
- **[GST RULE]** = the code decides a tax figure, which return/table/sheet/cell a figure belongs to, a state code, a period, etc. These are **described, never judged**. **TIME-VARYING** = a value that can change over time (table numbers, state lists, years).

### 0.3 Plain-English glossary (first use)

- *commit* = one saved change in the project history; *HEAD* = the latest commit; *diff* = the exact lines a commit added or removed.
- *docstring* = the descriptive text at the top of a Python file, class or function; *comment* = a `#` note inside code.
- *regex (regular expression)* = a text pattern the program uses to recognise file names.
- *Excel COM / win32com / pywin32 / pythoncom* = the Windows-only way a Python program remote-controls the real Microsoft Excel; `pywin32` is the package that provides the modules `win32com`, `pythoncom`, `win32api`, `win32con`, `win32gui`.
- *openpyxl* = a Python library that reads/writes .xlsx files without Excel (it cannot run Power Query).
- *Power Query (PQ)* = Excel's built-in data-import feature; the report templates use it to pull figures from the client files.
- *PyQt5 / Qt* = the window toolkit project B uses; *Tkinter (Tk)* = the older window toolkit the README describes.
- *QSS stylesheet* = Qt's colour/style rules (like a web page's CSS); a style set directly on one widget wins over the app-wide one.
- *thread / worker thread* = a second line of work running in the background so the window does not freeze.
- *import chain* = when file X loads file Y which loads Z; if Z cannot load, X cannot start.
- *dead code* = code that exists but is never used.
- *content type* = the label inside an .xlsx/.xltx/.xlsm package that tells Excel what kind of file it really is.
- *glob* = a file-name wildcard search such as `ITC_Report_*.xlsx`.
- *mtime* = a file or folder's "last modified" time.
- *stub* = a fake, empty stand-in module I created only inside my scratch run so B's window could be loaded on Linux.
