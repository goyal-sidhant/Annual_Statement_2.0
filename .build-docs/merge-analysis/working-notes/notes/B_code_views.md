## Plain-English terms used below

- **widget**: any visible piece of a window (button, text box, list...).
- **signal / slot**: Qt's messaging system. A widget or object "emits a signal" (for example "clicked"); any function "connected" to it (a "slot") then runs.
- **stylesheet (QSS)**: CSS-like text that sets colours, fonts and borders of widgets. A stylesheet can be set on the whole application or on one widget (then it also applies to that widget's children).
- **objectName**: a label given to a widget so that a stylesheet rule like `QPushButton#success` can target it.
- **layout**: an invisible arranger that places widgets in rows or columns.
- **splitter**: a divider between two panels that the user can drag to resize them.
- **model / item (QStandardItemModel, QStandardItem)**: the data store behind a list or tree; each cell is an "item".
- **check-state role**: the part of an item that holds "ticked / not ticked"; if it is set at all, Qt draws a check box in that cell.
- **worker thread**: a second line of execution so long jobs do not freeze the window. Qt widgets may only be touched from the main (window) thread.
- **queued connection**: when a signal is emitted in a worker thread, Qt delivers it later on the main thread, which keeps widget updates safe.
- **HTML**: the markup language of web pages; here the logs insert each message as a small HTML fragment.
- **text block**: one paragraph inside a Qt text box; Qt re-lays-out a whole block whenever text is added to it.
