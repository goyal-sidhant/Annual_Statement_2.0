### 0.1 Plain-English glossary (terms used below)

- Thread: a separate line of work inside the same program, running at the same time as the window. "Main thread" = the one that draws the window and reacts to clicks. "Worker thread" = a background one used for slow jobs so the window does not freeze.
- QThread / worker object / moveToThread: Qt's way of running a job in a worker thread. B creates a plain object (the "worker", e.g. ScanWorker) and moves it into a QThread; when the thread starts, the worker's run() method runs there.
- Signal / slot / connect / emit: Qt's messaging system. An object "emits" a signal (a named message, optionally with data); any function "connected" to it (a "slot") is then called. If the sender is in a worker thread and the receiver belongs to the main thread, Qt queues the message and the main thread runs the slot later ("queued connection"). This is the safe way to update the window from a worker.
- Event loop: the main thread's endless "wait for the next click/message, handle it" cycle.
- Modal dialog: a pop-up (QMessageBox) that blocks the rest of the window until closed.
- deleteLater: asks Qt to destroy an object at the next safe moment.
- Race condition: a bug that happens only when two things happen in an unlucky order/timing.
- abort / qFatal: in PyQt5 5.5 and later, an error that nothing catches inside a slot makes Qt stop the whole program at once (no save, no message).
- Stylesheet (QSS): CSS-like text that sets colours/fonts of Qt widgets. One set on the whole application applies everywhere unless a widget has its own stylesheet, which wins for that widget and its children.
- COM: the Windows mechanism a program (here Python, through pywin32) uses to drive Excel.
- Glob: matching file names with wildcards, e.g. "ITC_Report_*.xlsx".
- mtime: a file's or folder's "last modified" time.
- JSON: a plain-text data format; the app's settings files are JSON.
- Dataclass: a simple Python class that just holds named values (e.g. AppSettings).
- Re-export (__init__.py): a package's __init__.py imports names from its sub-files so other code can write "from gui import X".
- GIL: Python's internal lock that lets only one thread run Python code at a time; it makes single assignments safe but not multi-step updates.
