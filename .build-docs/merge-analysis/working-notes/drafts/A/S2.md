**Plain-English terms used in this section** (explained once here):
- *module* (one `.py` file of Python code); *package* (a folder of modules that contains an `__init__.py` file; Python runs that file whenever anything inside the folder is first used).
- *import* (one file asking to use code from another file); *re-export* (a package's `__init__.py` importing names from its own modules so that other code could write `from package import Name`); `__all__` (an optional list in a module naming what it "officially" offers).
- *class* (a blueprint for objects, for example the main window); *instantiate* (create an object from a class); *method* (a function that belongs to a class); *attribute* (a value stored on an object, written `self.name`).
- *parameter* (an input a function accepts); *default* (the value used when the caller gives none).
- *entry point* (the file a person runs to start a program).
- *dead code* (code that exists but is never used by the running program; it may still be used by the tests); *unreachable* (code that can never run because of how the code around it is written); *dormant* (code that could run, but the shipped configuration never makes it run).
- *AST* (abstract syntax tree: Python's own parsed form of a source file; my scripts read it to list every definition and every use without running the program).
- *callback* (a function handed to the window or to another function, to be called later, for example on a click, a timer `after(…)`, a variable `trace_add(…)`, or as the starting function of a *thread*, which is a second line of work running beside the window).
- *COM* (Windows' way for Python to drive Microsoft Excel; needs the `pywin32` package); *openpyxl* (a Python library that reads and writes `.xlsx` files without Excel); *Tk / Tkinter* (Python's built-in window toolkit, which A uses).
- *current folder* (the folder a program was started from; a file name with no folder part is created there); *home folder* (`%USERPROFILE%` on Windows, for example `C:\Users\<user>`); *system temp folder* (`%TEMP%` on Windows).
- *Power Query* (Excel's data-import tool; its queries live inside the report workbook and are re-run by "refresh"); *Links sheet* (the sheet of the ITC/Sales templates into which the program writes folder paths and file names that the template's queries then read); *staging copy* (a temporary local copy that is worked on and then copied to its final place).
- *pip* (Python's package installer); *pytest* (the tool that runs the automated tests); *virtual screen* (Xvfb, a screen that exists only in memory, so windows can be built on this Linux machine, which has no monitor); *ttk* (the newer, themable set of Tk widgets; a *ttk style* sets the colours of all widgets of one kind at once); *Tcl* (the scripting language underneath Tk); *Tk variable* (`StringVar`, `IntVar`, `BooleanVar`: a value the window shows and that the program reads with `.get()`).
- *daemon thread* (a worker thread that is killed at once, without clean-up, when the program ends); *lambda* (a small one-line function written in place, often used as a callback); *delegator* (a one-line method that only passes the call on to another object); *named record* (a `NamedTuple`: a small fixed set of named values, such as one checklist row).
- *glob* (a wildcard file search such as `Version-*`); *mtime* (a file's or folder's "date modified"); *stat* (the size, dates and type of a file as the operating system reports them; a *cached stat* is the copy that came with the folder listing, so the file need not be asked again); *file signature* (the first bytes of a file, which show whether it really is an Excel file); *8.3 short path* (an old DOS-style short alias of a long Windows path).
- *git* terms: *commit* (one saved change in the history); *blob hash* (git's fingerprint of a file's exact content; two files with the same hash are byte-identical); *trailer* (a `Key: value` line at the end of a commit message, such as `Co-Authored-By:`); *md5* (an older fingerprint method for file contents).
