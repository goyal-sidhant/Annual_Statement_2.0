**Plain-English terms used in this section** (explained once here):
- *module* (one `.py` file of Python code); *package* (a folder of modules that contains an `__init__.py` file; Python runs that file whenever anything inside the folder is first used).
- *import* (one file asking to use code from another file); *re-export* (a package's `__init__.py` importing names from its own modules so that other code could write `from package import Name`); `__all__` (an optional list in a module naming what it "officially" offers to `from package import *`); `__version__` / `__author__` (informal labels a module may carry).
- *class* (a blueprint for objects, for example the main window); *instantiate* (create an object from a class); *method* (a function that belongs to a class); *attribute* (a value stored on an object, written `self.name`); *property* (a method that is read like an attribute, without brackets); *dataclass* (a class that mainly holds named values, called fields).
- *parameter* (an input a function accepts); *default* (the value used when the caller gives none).
- *entry point* (the file a person runs to start a program).
- *dead code* (code that exists but is never used by the running program); *unreachable* (code that can never run because of how the code around it is written); *dormant* (code that could run, but the shipped configuration or screens never make it run); *write-only* (a value that is stored or saved but never read back).
- *AST* (abstract syntax tree: Python's own parsed form of a source file; the scripts used here read it to list every definition and every use without running the program).
- *signal / slot / connect / emit* (Qt's messaging system: an object *emits* a named *signal*; every function *connected* to it - a *slot* - then runs); *callback* (a function handed to another piece of code to be called later, for example on a click or by Windows when it lists windows); *worker thread* (a second line of work running beside the window so the window does not freeze; Qt's `QThread`).
- *COM* (Windows' way for one program to drive another, here Python driving Excel; needs pywin32); *openpyxl* (a Python library that reads and writes `.xlsx` files without Excel); *PyQt5* (the Python version of the Qt window toolkit that B uses).
- *current folder* (the folder a program was started from; a file name with no folder part is created there); *home folder* (`%USERPROFILE%` on Windows, for example `C:\Users\<user>`); *system temp folder* (`%TEMP%` on Windows).
- *Power Query* (Excel's data-import tool; its queries live inside the report workbook and are re-run by "refresh"); *Links sheet* (the sheet of the ITC and Sales templates into which the program writes folder paths and file names for the template's queries).
- *git* terms: *commit* (one saved change in the history); *blob hash* (git's fingerprint of a file's exact content); *trailer* (a `Key: value` line at the end of a commit message, such as `Co-Authored-By:`); *tracked* (a file git keeps in the repository; *ignored* = a file git is told never to keep, by `.gitignore`).
- *docstring* (the text in triple quotes at the top of a file, class or function that describes it; Python ignores it when running); *module-level function* (a function written directly in a file, not inside a class); *lambda* (a small unnamed one-line function, often handed to a button, a sort or a dictionary); *type hint* (a label such as `Optional` or `Tuple` that only documents what kind of value a function expects; Python does not check it).
- *event loop* (Qt's wait-for-clicks loop that keeps the window alive until it is closed); *objectName* (a name given to a screen element so that a style rule such as `QPushButton#primary` can target it); *HTML* (web-page formatting text, used here to colour log lines and the scan summary).
- *JSON* (a plain-text format for saved data, used by the settings files); *UTF-8* (a text encoding that can show any character, including ₹ and emoji); *stem* (a file name without its extension, e.g. `Report` for `Report.xlsx`); *stat* (asking Windows for a file's size and dates).
- *8.3 short path* (Windows' old-style shortened form of a long path, such as `C:\PROGRA~1\...`, used here as a retry when Excel cannot open a long path); *ZIP / OLE first bytes* (the fixed bytes at the start of every `.xlsx`/`.xlsm` file, which is a ZIP package, or of an old `.xls` file, which uses Microsoft's OLE format); *bare `except:`* (an error catcher that catches every error without naming it); *shebang line* (a first line such as `#!/usr/bin/env python` that tells Linux or macOS which program runs the file; Windows ignores it); *virtual environment* (a private Python installation for one project).
