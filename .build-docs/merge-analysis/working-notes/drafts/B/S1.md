## SECTION 1: EXECUTIVE SUMMARY

Project B is a Windows desktop program, "GST File Organizer v4.0", that takes **one folder holding many clients' GST Excel downloads**, recognises each file **only from its name** as one of six kinds - GSTR-2B Reco, IMS Reco, GSTR-3B Export, Sales, Sales Reco or Annual Report [GST RULE] ⚠ (`utils/constants.py:13-75`; apart from its size, dates and first 8 bytes, the Python code never reads a client file's contents, `core/file_parser.py:171-215`, Section 4.1) - groups the files per client and state, copies (never moves) them into a dated folder tree `Annual Statement-<DDMMYY HHMM>/<client>-<state code>/Version-<DDMMYY HHMM>/` (`core/file_organizer.py:67-298`), and builds for every client an **ITC report and a Sales report** from the author's own two Excel templates (pre-built workbooks the program fills in) by writing the copied files' folder paths and file names into each template's "Links" sheet, the sheet the template's Power Query reads (Power Query = Excel's built-in data-import tool; `core/excel_handler.py:65-217, 540-627`). In its fourth step it opens a time-stamped copy of each report in Microsoft Excel, makes Excel refresh the queries by pressing keys, checks one cell, reads 22 configured cells [GST RULE] ⚠ (`power_query_extractor/config/cell_mappings.py:33-228`) and writes them, for all clients, into one workbook `PQ_Extraction_Report_<YYYYMMDD_HHMM>.xlsx` (`power_query_extractor/core/data_consolidator.py:20-174`); every tax figure itself is produced inside the author's templates, which are not in the repository (Appendix X2.1).

It is built for the author's own CA/GST practice (HIGH: the audit method says the author is a CA/GST consultant who built the tool, `Project_Audit_FINAL.md:7`, and the file kinds and templates are those of an annual-statement job), where an annual-statement batch means sorting several downloads per client for many clients, pointing each client's two reconciliation workbooks at the right files, refreshing every workbook and copying the key figures into one summary - work B turns into one window of four tabs, "Step 1: Setup", "Step 2: Validation", "Step 3: Processing" and "Step 4: Extract & Refresh" (`gui/pyqt_main_window.py:90-93`); whether colleagues also run it, and on how many clients, is not recorded anywhere in the repository (NOT SURE - Appendix X6 Q51 and Q63 ask the author).
